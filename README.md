# 🏏 IPL Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on IPL cricket data.

The main purpose of this project is to analyze player performance and understand different statistics using Python, Pandas, Matplotlib, and Seaborn.

## 📊 Dataset

The dataset contains IPL player statistics such as:

- Player Name
- Team
- Runs
- Matches
- Innings
- Not Outs
- Highest Score
- Average
- Balls Faced
- Strike Rate
- 100s
- 50s
- 4s
- 6s

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 EDA Performed

The project includes:

- Data loading
- Data cleaning
- Data inspection
- Statistical analysis
- Player performance analysis
- Team-wise analysis
- Visualization of IPL statistics
- Comparison of player performance
- Different charts and plots using Matplotlib and Seaborn

## 📈 Visualizations

The project uses different visualizations to understand the data, including:

- Bar plots
- Count plots
- Scatter plots
- Box plots
- Histograms
- Heatmaps
- Pair plots

## 🎯 Project Objective

The objective of this project is to analyze IPL player statistics and extract meaningful insights from the dataset using Exploratory Data Analysis techniques.
